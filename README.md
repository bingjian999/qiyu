# 祁煜 · 桌面伙伴

祁煜是《恋与深空》中的人形角色。这个桌面小程序把**人形**的祁煜带到你的桌面上——他是「人」，不是宠物：会挥手问好、思考、散步、跑步、坐下、伸懒腰、惊讶、鞠躬，也会安静地陪你工作。

他称你为**家慧**。

## 功能

- **十种人物动作**：待机 / 挥手 / 思考 / 散步 / 跑步 / 坐下 / 伸懒腰 / 休息 / 惊讶 / 鞠躬（3D 半写实渲染精灵图）
- **人物化互动**：单击 → 他看你一眼，跟你搭话；双击 → 拍拍他的肩；长按 → 安静陪伴；托盘菜单可请他吃甜品
- **久坐提醒**：环形倒计时 + 到点弹窗 + 离座自动识别（45/3、60/5、30/2 预设可调）
- **定时提醒**：自定义 HH:MM 每日提醒
- **心情系统**：互动越频繁他越开心，长时间不理他心情会变低
- **时间感知**：早晨会跟你打招呼，深夜会安静下来
- **人物化台词**：他叫你「家慧」，说话像一个有分寸的人，绝无宠物腔

## 快速开始

需 Python 3.9+（[下载](https://www.python.org/downloads/)，安装时勾选 Add to PATH）。

```bash
python -m pip install -r requirements.txt
python main.py
```

Windows 用户直接双击 `run.bat` 即可。

## 操作说明

| 操作 | 效果 |
| --- | --- |
| 左键单击祁煜 | 随机反应动作 + 搭话 |
| 左键按住拖动 | 移动祁煜位置 |
| 双击 | 拍拍肩（他会吓一跳） |
| 长按 800ms | 安静陪伴 |
| 托盘菜单「请他吃甜品」 | 鞠躬致谢 + 吃完打招呼 |

**键盘快捷键**：

| 键 | 动作 |
| --- | --- |
| 空格 | 挥手问好 |
| W | 散步 |
| R | 跑步 |
| S | 休息 |
| F | 鞠躬 |
| H | 思考 |
| Y | 伸懒腰 |
| E | 坐下 |

闲置约 2 分钟后他会闭目养神；久坐提醒按设定的节奏工作。

## 打包 EXE（Windows）

不想装 Python？在 Windows 上双击 `build_exe.bat`，生成 `dist/qiyu.exe`，拷到任意目录双击即用。

## 测试

```bash
python -m pytest -q
```

## 技术说明

- `qiyu_pet/core.py` — 状态机 + 心情 + 久坐/定时提醒（无 Qt 依赖，纯逻辑可单测）
- `qiyu_pet/app.py` — PySide6 界面层（窗口 / 气泡 / 托盘 / 提醒面板）
- `qiyu_pet/sprites/qiyu/` — 10 张透明 PNG 精灵图（3D 半写实渲染，已按主体裁边）
- `tests/` — 54 个 pytest 单元测试（UIH 前缀）
